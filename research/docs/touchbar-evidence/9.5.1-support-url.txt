# --- Notes ---
#
# 1. The canonical Touch Bar settings article uses the newer "mac-help guide"
#    URL format (support.apple.com/guide/mac-help/<slug>-<id>/mac), NOT the
#    older HT-prefixed article ID format. The article ID is mchlc050704e.
#    This is Apple's current documentation URL scheme as of macOS Ventura/Tahoe.
#
# 2. The function-key article (108316) uses the older numeric format and
#    explicitly confirms the press-and-hold Fn behavior. No timing slider
#    is documented — supporting the 9.4.2 finding that timing is hardcoded
#    in TouchBarServer/ControlStrip binaries.
#
# 3. The Mac User Guide is versioned by macOS version. To get the Ventura-
#    specific version, append /13.0/mac/13.0 to the guide URLs. The
#    generic /mac URL serves the latest version (Tahoe), which may not
#    include Touch Bar articles going forward.
