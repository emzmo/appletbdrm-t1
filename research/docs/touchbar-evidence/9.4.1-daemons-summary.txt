# 9.4.1 — dfrd / DFRDaemon / controlstripd daemon names [HIGH] — RESOLVED
# Date: 2026-08-25
# Machine: MacBookPro14,2, macOS 13.7.8 (22H730)
#
# [REFUTED] The checklist's [SUSPECTED] names are WRONG for macOS 13.7.8:
#   - "dfrd"           — does NOT exist (no process, no launchd service, no binary)
#   - "DFRDaemon"      — does NOT exist (no process, no launchd service, no binary)
#   - "controlstripd"  — does NOT exist (no process, no launchd service, no binary)
#
# [CONFIRMED] Actual macOS Touch Bar daemon names on macOS 13.7.8:
#
# Running processes:
#   1. TouchBarServer (PID 313)
#      Binary: /usr/libexec/TouchBarServer
#      Role: Userspace USB display driver for the Touch Bar OLED.
#            Claims interface 3 (the appletbdrm display endpoint,
#            bInterfaceClass=0x10, UsbExclusiveOwner="pid 313, TouchBarServer").
#            Entitlement required: com.apple.appledfr.client
#            This is the low-level driver that sends framebuffer updates.
#
#   2. ControlStrip (PID 468 → restarted to 877 during 9.5.2 test)
#      Binary: /System/Library/CoreServices/ControlStrip.app/Contents/MacOS/ControlStrip
#      Role: High-level Touch Bar agent — decides WHAT to show (Control Strip
#            items, app items, function keys). Reads PresentationModeGlobal
#            from com.apple.touchbar.agent defaults domain.
#            Launchd label: com.apple.controlstrip (LaunchAgent, running)
#
#   3. SpacesTouchBarAgent (not in ps output at capture time, but service exists)
#      Binary: /System/Library/CoreServices/SpacesTouchBarAgent.app/Contents/MacOS/SpacesTouchBarAgent
#      Launchd label: com.apple.SpacesTouchBarAgent.app (LaunchAgent, on-demand)
#      Role: Spaces/multi-desktop Touch Bar integration.
#
# launchd service labels (from launchctl list + launchctl print gui/501):
#   Running:
#     - com.apple.controlstrip (PID 468, state=running, LaunchAgent)
#   On-demand (not running, state=D):
#     - com.apple.accessibility.dfrhud       (Accessibility DFR HUD)
#     - com.apple.SpacesTouchBarAgent.app    (Spaces Touch Bar agent)
#     - com.apple.SpacesTouchBarService      (Spaces Touch Bar service)
#     - com.apple.LocalAuthentication.DFR    (Touch ID / LocalAuthentication DFR)
#     - com.apple.ServicesTouchBarService    (Services Touch Bar service)
#   Plist exists but no launchctl entry:
#     - com.apple.touchbarserver            (LaunchDaemon plist at
#         /System/Library/LaunchDaemons/com.apple.touchbarserver.plist)
#         — likely the TouchBarServer daemon definition (system-level, not
#           user-level; runs as root, which is why PID 313 is /usr/libexec/)
#
# --- Launchd details for com.apple.controlstrip (the primary agent) ---
#   path = /System/Library/LaunchAgents/com.apple.controlstrip.plist
#   type = LaunchAgent
#   state = running
#   program = /System/Library/CoreServices/ControlStrip.app/Contents/MacOS/ControlStrip
#   pid = 468 (initial), 877 (after kickstart in 9.5.2 test)
#   event triggers:
#     com.apple.touchbar.matching => {
#       keepalive = 1
#       service = com.apple.controlstrip
#       stream = com.apple.touchbar.matching
#       monitor = com.apple.UserEventAgent-Aqua
#       descriptor = { "State" => true }
#     }
#   (The agent is kept alive by a stream called "com.apple.touchbar.matching"
#    monitored by com.apple.UserEventAgent-Aqua. This is how the Touch Bar
#    agent is started/maintained.)
#
# --- Mapping to the checklist's [SUSPECTED] names ---
#   The checklist suspected "dfrd" / "DFRDaemon" — neither exists. The
#   "DFR" acronym appears in:
#     - com.apple.accessibility.dfrhud    (DFR HUD for accessibility)
#     - com.apple.LocalAuthentication.DFR  (DFR for Touch ID prompts)
#     - UsbUserClientEntitlementRequired = "com.apple.appledfr.client"
#       (the entitlement TouchBarServer uses to claim interface 3)
#   So "DFR" (Dynamic Function Row) is an Apple-internal acronym used in
#   service labels and entitlements, but there is no standalone "dfrd" or
#   "DFRDaemon" binary. The DFR functionality is split between:
#     - TouchBarServer (display driver, /usr/libexec/)
#     - ControlStrip (UI agent, /System/Library/CoreServices/ControlStrip.app/)
#     - com.apple.LocalAuthentication.DFR (Touch ID DFR prompts, on-demand)
#     - com.apple.accessibility.dfrhud (accessibility DFR HUD, on-demand)
#
#   The checklist suspected "controlstripd" — the actual binary is
#   "ControlStrip" (no "d" suffix), running as
#   /System/Library/CoreServices/ControlStrip.app/Contents/MacOS/ControlStrip.
#   It's a .app bundle, not a raw daemon binary.
#
