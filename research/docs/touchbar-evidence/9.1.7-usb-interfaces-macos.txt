# Promotion: docs/01-hardware.md §1.5 [SUSPECTED] → [CONFIRMED]
#   Interface 7 IS the Touch ID / SEP control channel, class 0xff/0xf9/0x11,
#   2 endpoints (bulk 512-byte EP5 OUT + EP8 IN, per Linux-side endpoint dump).
#
# Note on endpoint numbers: ioreg does not expose individual endpoint addresses
# in the IOUSBHostInterface node (only bNumEndpoints=2). The EP5/EP8 detail
# comes from the Linux-side usbhid-dump / lsusb output. This macOS ioreg
# confirms the interface-level identity (class/subclass/protocol + name).
#
# Driver chain: IOUSBHostInterface@7 → KernelRelayHost (kernel relay) →
#   (userspace) AppleSEPManager / SEP daemons. NOT a direct "Touch ID" daemon
#   on the macOS side — the SEP relay is mediated by KernelRelayHost, which
#   bridges to LocalAuthentication.framework daemons (com.apple.LocalAuthentication.*).
#   See 9.4.1-launchd-details.txt for the LocalAuthentication.DFR service label.
